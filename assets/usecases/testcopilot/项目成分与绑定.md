# TestCopilot — 项目成分与绑定用例提纲

对应 `tests/features/testcopilot/*.feature`。绑定类场景与浏览类场景分开，避免 Background 造过多数据。

## 配置

- 未登记数据源时，配置页说明可添加本地挂载。
- 添加本地挂载后，数据源列表出现该名称。
- 将 Formulation / 环境 / TestCopilot 绑到同一数据源并保存。
- 选择 Git URL 类型时，同步应提示尚未提供 clone/fetch。

## 未绑定引导

- Formulation / 环境 / TestCopilot / 作业在未绑定对应数据源时，展示引导并提供进入配置的入口。

## Formulation（已绑定）

- 场景页列出约定扫描到的 Feature 与 Scenario。
- 可从场景引用到 TestCopilot 新建测程。
- 可浏览 action words / API / Page / DDL；执行 action word 在 TestCopilot 未绑定时被阻止。

## 环境（已绑定）

- 展示连接目标与数据源别名。
- 不展示密码或 token 明文；至多展示密钥键名。

## TestCopilot（已绑定）

- 总览展示仓库与资产计数入口。
- 常用 SQL、pytest 节点可浏览。
- 引用 Formulation 场景创建测程后，详情为待执行、报告未回填。

## 作业

- 未填表名运行 dump_ddl 应看到需要表名的提示。
- 白名单工具运行后，作业列表/详情出现对应类型记录。
- 非白名单工具显示不可运行。
