# Plane 开源社区版 — 业务能力（dogfood 生成依据）

> 被测系统是 [Plane](https://github.com/makeplane/plane) 开源项目管理工具。本笔记只记录 **社区版产品能力**，不写选择器、接口路径或表名。
> 产品中文名以 Plane `zh-CN` 文案为准（工作项 / 周期 / 模块 / 视图 / 页面）。

## 产品定位

Plane 用于跟踪工作项、跑周期（官方 README 中的 Cycles，社区中文为「周期」）、管理产品路线，而尽量不把工具本身变成负担。社区版核心模块如下。

## 工作项（Work Items）

- 工作项是项目的构建块：创建、编辑标题、分配负责人、设置优先级、跟踪进度。
- 支持富文本与文件上传；可加子工作项、父工作项、依赖与关系。
- 列表可用多种布局查看（列表 / 看板 / 日历 / 表格 / 时间线）。
- 空项目会引导「创建您的第一个工作项」。

## 周期（Cycles）

- 把工作分组并限时；可从项目截止日期倒推设置开始/结束日期。
- 活动周期可看进度、燃尽图、高优先级工作项、按负责人/标签的明细。
- 空周期提示「此周期中没有要显示的工作项」，可新建或添加已有工作项。
- 周期有尚未开始 / 进行中 / 已完成 / 草稿等状态；已完成的周期可归档。

## 模块（Modules）

- 把复杂项目拆成可跟踪的阶段；模块由相互关联的工作项组成。
- 可监控阶段进度与截止日期。
- 空模块同样引导创建或添加已有工作项。

## 视图（Views）

- 视图是保存下来的过滤器，用来只看当前最相关的工作项。
- 可保存、再打开、与团队共享；空项目引导「创建视图」。

## 页面（Pages）

- 用富文本页面捕捉与组织想法；可格式化文字、插图、链接，并把笔记转成可执行工作项。
- 页面有大纲、文档信息、版本历史与评论。

## 分析（Analytics）

- 跨 Plane 数据看实时洞察：趋势、阻塞、项目是否在推进。
- 工作区级分析入口与项目内周期燃尽是不同入口，断言时只验证「能看到洞察区域」，不要写死图表数值。

## 工作区与项目（壳）

- 用户登录后进入工作区；工作区下有项目列表。
- 项目侧栏（社区版）可见：工作项、周期、模块、视图、页面，以及（本 fork 另增的 TestCopilot 成分，见另一篇笔记）。
- 本仓库 dogfood **不**把 Issue 当成测试用例副本；官方 Issue/工作项只回归缺陷与任务管理本身。

## 明确不覆盖（避免写出无法稳定自动化的场景）

- 商业版 / God mode / 实例级 SSO 域名验证。
- 固定等待、「接口正常」这类不可观测断言。
- 把 token / cookie / 密码写进用例正文（登录用「已配置的测试账号」）。
